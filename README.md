# 42 São Paulo — Basecamp

Exercícios desenvolvidos durante estudos introdutórios de programação na 42 São Paulo.

## Conteúdo

- `C/`: exercícios de fundamentos da linguagem C.
- `Shell/`: exercícios de linha de comando e shell script.

Os diretórios seguem a organização adotada nas listas de exercícios, como `C00`, `C01` e seus respectivos `ex00`, `ex01` etc.

## Objetivo

Este repositório registra minha evolução nos fundamentos de programação, incluindo:

- lógica de programação;
- funções e manipulação de dados em C;
- compilação e execução pelo terminal;
- comandos e scripts de shell.

## Observação

Arquivos compilados, como `a.out`, não fazem parte do código-fonte e passam a ser ignorados nas próximas alterações.
